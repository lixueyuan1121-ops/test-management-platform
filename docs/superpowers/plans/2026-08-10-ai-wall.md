# AI 战绩墙 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 QA Copilot 已沉淀的 `ai_task`/`test_case` 数据聚合成一张可按区间查询的 AI 战绩墙页面，并升级测试点评审为三态以支撑"采纳/已评审"口径。

**Architecture:** 后端在 `stats.py` 加一个只读区间聚合端点（现算，不建统计表）；`test_case` 加 `review_status`+`reviewed_at` 两列（加列不改列，保留 `adopted` 兼容）；`PATCH /testcases/{cid}` 升级为设三态状态；前端新增 `AIWall.vue`，从已校验的原型移植图表，加时间范围选择器与可调折算系数。

**Tech Stack:** FastAPI + SQLAlchemy 2.0（SQLite 默认/MySQL 生产），Vue3 + Vite + ElementPlus + Pinia，手写 SVG 图表（无图表库）。

## Global Constraints

- 统一响应信封 `{code,msg,data}`：后端用 `app/schemas/common.py` 的 `ok(data)`/`fail`；前端 `api/http.js` 拦截器已解包（`code===0` 返回 `data` 本身）。
- 不建统计表：对 `ai_task`/`test_case` 现算聚合（沿用 stats.py 铁律）。
- 序列化不用 `response_model`，每个 router 手写 `_to_out(db,obj)->dict`（枚举取 `.value`、日期 `isoformat`）。
- 枚举放 `app/core/enums.py`（不放 models，避免循环导入）。
- 增量改列走 `app/db/migrate.py` 手写 `ALTER TABLE ADD COLUMN`（仿 `ensure_task_columns`），startup 调用；幂等（先探列存在再加）。
- 两份 schema 手动同步：SQLAlchemy 模型（`app/models/`）与 `backend/sql/schema.sql`。
- 本仓库**无测试框架**（不要臆造 pytest/eslint）。所有"验证"是手动端到端：`curl` 打接口 + 浏览器看页面。
- 前端别名 `@`→`frontend/src`；接口函数集中在 `api/index.js`（返回已解包 data）。
- 权限：复用 `app/core/deps.py` 的 `assert_project_role` / `_visible_project_ids`；两级 RBAC（平台管理员绕过、项目角色 admin/member/guest）。
- 分支：`feat/ai-wall`（已创建，spec 已提交其上）。

```python
def ensure_testcase_columns(engine) -> None:
    """test_case 增量列：review_status / reviewed_at（仿 ensure_task_columns）。
    老库回填：adopted=1 → review_status='adopted', reviewed_at=created_at；其余 pending。"""
    cols = _existing_columns(engine, "test_case")   # 复用现有探列辅助；若无则仿 ensure_task_columns 内联查询
    with engine.begin() as conn:
        if "review_status" not in cols:
            conn.exec_driver_sql(
                "ALTER TABLE test_case ADD COLUMN review_status VARCHAR(16) NOT NULL DEFAULT 'pending'")
        if "reviewed_at" not in cols:
            conn.exec_driver_sql("ALTER TABLE test_case ADD COLUMN reviewed_at DATETIME NULL")
        # 回填旧数据（仅当刚加列时执行一次；重复执行也幂等：只改仍为 pending 但 adopted=1 的行）
        conn.exec_driver_sql(
            "UPDATE test_case SET review_status='adopted', reviewed_at=created_at "
            "WHERE adopted=1 AND review_status='pending'")
```

注意：若 `migrate.py` 里已有统一的"探列"辅助（如 `ensure_task_columns` 内联用了 `PRAGMA table_info` 或 information_schema），照它的写法来，别引入新风格。SQLite 与 MySQL 的探列语句可能不同——沿用 `ensure_task_columns` 已有的兼容做法。

```python
@router.patch("/testcases/{cid}")
def review_testcase(
    cid: int,
    body: TestCaseReviewIn,
    db: Session = Depends(get_db),
    user: User = Depends(get_current_user),
):
    """采纳 / 否决 / 置回待定一条测试点。写 reviewed_at，同步 adopted 兼容列。"""
    tc = db.get(TestCase, cid)
    if not tc:
        raise HTTPException(status.HTTP_404_NOT_FOUND, detail="测试点不存在")
    assert_project_role(db, user, tc.project_id, _WRITE_ROLES)
    tc.review_status = body.review_status
    if body.review_status == ReviewStatus.pending:
        tc.reviewed_at = None
    else:
        tc.reviewed_at = datetime.now()
    tc.adopted = (body.review_status == ReviewStatus.adopted)
    db.commit()
    db.refresh(tc)
    return ok(_to_case_out(tc))
```

```python
@router.get("/ai")
def ai_stats(
    from_date: date = Query(default=None, alias="from"),
    to_date: date = Query(default=None, alias="to"),
    db: Session = Depends(get_db),
    user: User = Depends(get_current_user),
):
    """AI 战绩墙聚合：区间内生成/采纳/成本/耗时 + 维度/优先级分布 + 按天趋势。
    生成类按 test_case.created_at 筛；采纳类按 reviewed_at 筛。现算聚合，不建表。"""
    from app.models import AiTask, TestCase
    from app.core.enums import ReviewStatus, AiTaskStatus

    today = date.today()
    to_d = to_date or today
    from_d = from_date or (to_d - timedelta(days=29))   # 默认近 30 天
    scope = "platform" if user.is_platform_admin else "member"
    pids = _visible_project_ids(db, user)

    DIMS = ["功能", "边界", "异常", "兼容", "性能"]
    PRIOS = ["P0", "P1", "P2", "P3"]

    def empty():
        days = (to_d - from_d).days
        trend = [{"date": str(from_d + timedelta(days=i))[5:], "generated": 0, "adopted": 0}
                 for i in range(days + 1)]
        return ok({"scope": scope, "project_cnt": 0, "from": str(from_d), "to": str(to_d),
                   "total_generated": 0, "run_cnt": 0, "total_cost_usd": 0.0, "avg_duration_s": 0.0,
                   "dims": [{"name": n, "count": 0} for n in DIMS],
                   "total_reviewed": 0, "total_adopted": 0, "adopt_rate": 0.0,
                   "prio": [{"p": p, "n": 0} for p in PRIOS], "trend": trend})

    if not pids:
        return empty()
    # ... 后续步骤填充聚合
```

- [ ] **Step 2: 生成类聚合（按 created_at）**

在 `if not pids: return empty()` 之后，续写。用 SQLAlchemy `func`（文件已 import）：

```python
    # 生成类：test_case.created_at ∈ [from, to]（含边界，to 当天到 23:59:59 用 < to+1 天处理日期比较）
    gen_base = db.query(TestCase).filter(
        TestCase.project_id.in_(pids),
        func.date(TestCase.created_at) >= from_d,
        func.date(TestCase.created_at) <= to_d,
    )
    total_generated = gen_base.count()

    # 维度覆盖计数（固定 5 类，缺补 0）
    dim_rows = (db.query(TestCase.category, func.count(TestCase.id))
                .filter(TestCase.project_id.in_(pids),
                        func.date(TestCase.created_at) >= from_d,
                        func.date(TestCase.created_at) <= to_d)
                .group_by(TestCase.category).all())
    dim_map = {k: v for k, v in dim_rows}
    dims = [{"name": n, "count": int(dim_map.get(n, 0))} for n in DIMS]

    # ai_task：done 次数 / 成本 / 平均耗时（按 ai_task.created_at 区间）
    at_base = db.query(AiTask).filter(
        AiTask.project_id.in_(pids),
        func.date(AiTask.created_at) >= from_d,
        func.date(AiTask.created_at) <= to_d,
    )
    run_cnt = at_base.filter(AiTask.status == AiTaskStatus.done).count()
    total_cost = (db.query(func.coalesce(func.sum(AiTask.cost_usd), 0))
                  .filter(AiTask.project_id.in_(pids),
                          func.date(AiTask.created_at) >= from_d,
                          func.date(AiTask.created_at) <= to_d).scalar() or 0)
    avg_ms = (db.query(func.avg(AiTask.duration_ms))
              .filter(AiTask.project_id.in_(pids),
                      func.date(AiTask.created_at) >= from_d,
                      func.date(AiTask.created_at) <= to_d,
                      AiTask.status == AiTaskStatus.done,
                      AiTask.duration_ms.isnot(None)).scalar())
    avg_duration_s = round(float(avg_ms) / 1000, 1) if avg_ms else 0.0
```

- [ ] **Step 3: 采纳类聚合（按 reviewed_at）**

```python
    # 采纳类：test_case.reviewed_at ∈ [from, to]
    rev_filter = [TestCase.project_id.in_(pids),
                  TestCase.reviewed_at.isnot(None),
                  func.date(TestCase.reviewed_at) >= from_d,
                  func.date(TestCase.reviewed_at) <= to_d]
    total_reviewed = (db.query(func.count(TestCase.id))
                      .filter(*rev_filter,
                              TestCase.review_status.in_([ReviewStatus.adopted, ReviewStatus.rejected]))
                      .scalar() or 0)
    total_adopted = (db.query(func.count(TestCase.id))
                     .filter(*rev_filter, TestCase.review_status == ReviewStatus.adopted)
                     .scalar() or 0)
    adopt_rate = round(total_adopted / total_reviewed, 3) if total_reviewed else 0.0

    # 采纳测试点优先级分布（固定 P0-P3，缺补 0）
    prio_rows = (db.query(TestCase.priority, func.count(TestCase.id))
                 .filter(*rev_filter, TestCase.review_status == ReviewStatus.adopted,
                         TestCase.priority.isnot(None))
                 .group_by(TestCase.priority).all())
    prio_map = {k: v for k, v in prio_rows}
    prio = [{"p": p, "n": int(prio_map.get(p, 0))} for p in PRIOS]
```

- [ ] **Step 4: 趋势聚合（按天，覆盖整区间）**

```python
    # 趋势：每天 generated（按 created_at）+ adopted（按 reviewed_at）
    gen_day = dict(db.query(func.date(TestCase.created_at), func.count(TestCase.id))
                   .filter(TestCase.project_id.in_(pids),
                           func.date(TestCase.created_at) >= from_d,
                           func.date(TestCase.created_at) <= to_d)
                   .group_by(func.date(TestCase.created_at)).all())
    adopt_day = dict(db.query(func.date(TestCase.reviewed_at), func.count(TestCase.id))
                     .filter(*rev_filter, TestCase.review_status == ReviewStatus.adopted)
                     .group_by(func.date(TestCase.reviewed_at)).all())
    # func.date 在 SQLite 返回 'YYYY-MM-DD' 字符串，MySQL 返回 date；统一转 str 再比对
    def _k(x): return str(x)
    gen_day = {_k(k): v for k, v in gen_day.items()}
    adopt_day = {_k(k): v for k, v in adopt_day.items()}
    days = (to_d - from_d).days
    trend = []
    for i in range(days + 1):
        d = from_d + timedelta(days=i)
        ds = str(d)
        trend.append({"date": ds[5:],  # MM-DD
                       "generated": int(gen_day.get(ds, 0)),
                       "adopted": int(adopt_day.get(ds, 0))})
```

- **时间范围选择器**：`el-radio-group` 预设（近7天/近30天/近90天/本月至今）+ `el-date-picker` 自定义 range。默认近 30 天。切换 → 重算 from/to → 重新 `aiStats`。用本机日期计算 from/to（`new Date()`），传 `YYYY-MM-DD`。
- KPI 脚注去掉原型里的 `p95 34s`（本版无 p95），"平均生成耗时"只显 avg。
- 明暗主题：dark 变量同时声明在 `@media (prefers-color-scheme: dark)` 与 `[data-theme="dark"]` 两个 scope（原型已修此坑，移植时保留两份）。是否加页内明暗切换按钮由页面统一主题决定——若平台本身无暗色，则移除 toggle，只保留亮色（但仍保留 dark 变量块以备将来）。**确认平台当前是否有暗色模式**：读 Dashboard/theme.css，若全站仅亮色，则 AIWall 也只亮色，移除 toggle 按钮。
- 空态：`stats.total_generated===0 && 无采纳 && trend 全 0` → 显示仿 Dashboard 的空态卡（"所选区间暂无 AI 生成数据"）。

```vue
<script setup>
import { ref, computed, onMounted } from 'vue'
import { aiStats } from '@/api'

const stats = ref(null)
const loading = ref(false)
const factor = ref(Number(localStorage.getItem('tp_ai_save_factor')) || 0.5)
const range = ref('30d')   // '7d'|'30d'|'90d'|'mtd'|'custom'
const customRange = ref([])

function calcFromTo() {
  const to = new Date()
  let from = new Date()
  if (range.value === '7d') from.setDate(to.getDate() - 6)
  else if (range.value === '30d') from.setDate(to.getDate() - 29)
  else if (range.value === '90d') from.setDate(to.getDate() - 89)
  else if (range.value === 'mtd') from = new Date(to.getFullYear(), to.getMonth(), 1)
  else if (range.value === 'custom' && customRange.value?.length === 2)
    return { from: customRange.value[0], to: customRange.value[1] }
  const fmt = d => `${d.getFullYear()}-${String(d.getMonth()+1).padStart(2,'0')}-${String(d.getDate()).padStart(2,'0')}`
  return { from: fmt(from), to: fmt(to) }
}

async function load() {
  loading.value = true
  try { stats.value = await aiStats(calcFromTo()) }
  catch { stats.value = null }
  finally { loading.value = false }
}

const savedHours = computed(() => Math.round((stats.value?.total_adopted || 0) * factor.value))
const adoptRatePct = computed(() => ((stats.value?.adopt_rate || 0) * 100).toFixed(1))
// ...趋势/维度/优先级的 computed 派生（坐标、路径），移植原型算法

function onFactorChange(v) { factor.value = v; localStorage.setItem('tp_ai_save_factor', String(v)) }
function onRangeChange() { load() }

onMounted(load)
</script>
```
