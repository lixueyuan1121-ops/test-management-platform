# 平台 UI 与交互改版

## 目标与边界

统一导航、页面层级、筛选与批量操作、详情阅读和确认流程。保留现有 URL、权限判断、接口、任务调度与判定语义。不同模块分批验收，不通过全局覆盖样式强行改造所有页面。

## 导航结构

- 工作空间：工作台、测试指挥官、我的日报。
- 对话测评：测评任务、用例库、测评生成、测评结果。
- 功能测试：测试计划、任务分配、AI 测试助手、用例资产、执行结果与遗留问题。
- 反馈回归：导入记录、反馈用例、回归集、回归结果。
- 性能测试：任务下发、性能报告。
- 质量与发布：作战大屏、需求覆盖、上线 checklist、发版记录、统计与质量分析。
- 设备与工具：设备看板、我的设备、工具广场。
- 系统管理：项目、用户、选择器、API 环境、工具配置；只对管理员显示。

默认展开当前模块；侧栏功能搜索仅搜索当前身份有权访问的入口。保留折叠状态，路由切换后显示所属模块和当前页面，并重置主内容区滚动。

## 页面规则

1. 列表页采用页标题 + 操作栏 + 数据列表，不以大卡片包整页。主操作突出，低频操作收进菜单，停止与删除保留确认。
2. 搜索、筛选、已选数量、提交操作需要能在长列表中访问；窄屏可以折叠配置，不能让固定区域占满屏幕。
3. 编辑表单使用受视口约束的滚动内容区，保存与取消留在固定底部。选择资产时提供“全部 / 已选”视图，跨筛选保留选择。
4. 详情分为结果、报告等标签，不在长表格末尾堆报告。标签与批次选择吸顶，行动按钮随当前标签出现。
5. 长提问、预期和原始证据在侧栏阅读；列表只显示摘要。缺记录与失败明确区分，不通过 UI 捏造成功状态。
6. 相同配色与尺寸：石墨侧栏、白色工作区、钴蓝主操作；红/绿/琥珀仅表达状态；间距以 4/8px 为基准，固定工具面板圆角不超过 8px。

本轮：全局导航 + 测评任务列表/详情/编辑 + 测评用例库的阅读与下发确认；保留已完成的结果侧栏与吸顶操作栏。

后续：功能测试全链路、反馈回归与性能模块、设备和质量看板、低频管理页。每一批复用上述规则，单独补关键流程测试；不把未验收模块标记为完成。
