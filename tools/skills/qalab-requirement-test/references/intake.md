# 快捷调用与输入卡片


用户只发送 `$qalab-requirement-test`、选择技能的快捷入口，或说“开始一次需求测试”但未提供本次需求时，先展示输入卡片，让用户直接填写，不要求粘贴固定格式。若用户是在修改、安装、导出或咨询这个技能，按其实际请求处理，不因消息里含技能名或测试示例而启动测试。

优先调用当前可用的 `request_user_input_async`（本环境为 `functions.request_user_input_async`），一次展示本次缺少的输入项。单独调用时使用下面的参数；需求和应用地址是自由文本，项目与关联任务分别将建议项“纳米Work PC端”和“codex导入用例”放在第一位，利用客户端默认选中能力，用户可直接提交或改填项目名：

```json
{
  "questions": [
    {"title": "本次要验证什么需求？直接描述操作和预期结果即可。"},
    {"title": "待测应用地址是什么？填写网页 URL 或本机应用的完整路径。"},
    {"title": "回填环境：默认线上；选择本地测试则回填到 http://localhost:8000，也可直接填写其他测试平台地址。", "options": ["线上（默认）：https://qalab.claw.qihoo.net", "本地测试：http://localhost:8000"]},
    {"title": "回填到哪个项目？默认已选“纳米Work PC端”，也可以输入其他项目名。", "options": ["纳米Work PC端"]},
    {"title": "关联任务（可选）：不填使用“codex导入用例”，也可以输入指定任务名。", "options": ["codex导入用例"]}
  ]
}
```

- 这是当前任务的信息收集，不是额外授权确认；填完后按原有测试和异步提交流程继续，不再重复问“是否开始”。
- 单独调用意味着新的一次需求收集，不自动拿历史已完成任务、技能文档或消息中的格式示例当作本次需求。用户在当前测试请求中已提供的字段不重复询问；需求和应用地址已齐全而未指定项目时，采用默认项目“纳米Work PC端”继续。
- 关联任务为可选项。填写时去除首尾空白后使用用户指定的任务名；未填写、空白或跳过时默认“codex导入用例”。已有需求和应用地址时，不为这个可选项单独阻塞测试；简短说明所用任务名即可。生成导入包时将最终名称写入顶层 `task_name`，不能误填到 `requirement` 或使用本机任务 ID。
- 回填环境为可选项。整张卡片已提交而未填写环境时使用线上；需求和应用地址已完整给出时，无需为环境再弹卡，明确说明“本次回填：线上 https://qalab.claw.qihoo.net（可改为本地测试）”后继续。用户选择本地测试时使用其当前指定地址，未另行指定则为 http://localhost:8000。环境选项只控制平台数据读写，不改变待测应用地址，也不自动修改 Runner 配置或搬迁已有用例。
- 应用地址不设所有人通用的 Windows 路径；支持同事自己的 Windows/macOS 路径和网页地址。用户明确要求沿用本次测试已确认的地址时可以沿用。
- 异步输入工具返回后，必须等用户实际回复。未填写必需的需求或应用地址、取消或未提交时，不启动应用、不执行测试、不回填；项目的预选不代表用户已提交整张卡片。只补问仍缺少的字段，不能靠等待超时编造输入。
- `request_user_input_async` 返回 `accepted` 只表示问题已发出，不是用户答复。问题待答期间不要紧接着发送 final（例如“请填写上方卡片”）或结束当前轮；保持当前任务等待，直到用户提交、明确取消或转去处理别的请求。
- 发出卡片后可以做不依赖答案的准备；没有独立工作时，使用宿主可用的可中断等待能力（如 `clock.sleep`，每次不超过 60 秒），收到新消息立即处理。等待到期不等于用户回答，不重复弹卡、不使用默认值启动测试，也不创建后台监控任务。没有可用等待能力时，改为在聊天中列出缺少字段，不承诺卡片会持续显示。
- 用户反馈卡片消失或难以填写时，保留已经收到的需求、地址及项目，允许直接在聊天中补充剩余项；用户要求重弹时只重发缺少项并遵守上面的等待规则。不要把反馈误当成取消测试，也不要要求从头再填。卡片的具体显示时长由宿主控制，不声称 skill 已修改了宿主的超时或保证弹窗永久保留。
- 用户可以把多个字段写在同一个回答里，也可以用自然语言直接发来，均应提取并沿用，无需重新格式化或再次填卡片。
- 如当前宿主没有可用的输入卡片工具，在对话中一次简短收集“需求、应用地址”，注明“回填默认线上，可选本地测试；项目默认纳米Work PC端，关联任务默认codex导入用例，均可修改”，然后等待回复。不要为了收集这些字段安装工具、启动本地服务或创建新任务；不要声称已经弹出宿主未提供的窗口。
- 卡片得到的是项目名称。随后仍需用当前账号查询线上项目列表并匹配真实 ID；默认项目不存在或无权限时提示用户选择可访问项目，不擅自改到别的项目或 localhost。
